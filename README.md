# Customer Segmentation using K-Means Clustering

## Description
This project groups customers into different clusters based on their Annual Income and Spending Score.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- Scikit-learn

## Dataset
Mall Customers Dataset

## Algorithm
- K-Means Clustering

## Steps
1. Load dataset
2. Select features
3. Train K-Means model
4. Predict customer clusters
5. Visualize clusters

## Output
- Clustered customers
- Cluster graph

## Result
Customers are successfully divided into different groups for marketing analysis.
